This is the frontend part of my self-designed resume website.
It is built with React and connects to a backend API to handle form submissions.
The backend is available in a separate repository: myresumebackend

 Tech Stack
React

Axios for HTTP requests

CSS / HTML for styling

React Hooks (useState, useEffect)

Modern functional components

Features
Clean and modern design for showcasing my resume

Responsive layout for desktop and mobile

Contact form to send messages to the backend

Displays confirmation messages on successful form submission
